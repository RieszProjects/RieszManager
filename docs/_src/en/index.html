RieszManager

Manage Claude Code sessions from your browser

RieszManager (shown as “Riesz” in the UI) is a self-hosted web application for viewing and controlling all Claude Code sessions on a machine from your browser. Whether you are at your desk or away with just your phone, you can open the page at any time to check progress, approve prompts, or start new tasks.

What is RieszManager

RieszManager is a self-hosted web app that lets you view and control all Claude Code sessions on a single machine from one place in your browser. It works on both desktop and mobile, and on mobile you can install it to your home screen as a standalone app (PWA).

Messages you see and send in the browser map directly to the session logs in ~/.claude on your machine—they are not separate copies. You can pick up a conversation started in the terminal right in the browser; conversely, after continuing a session in the browser, you can head back to the terminal and resume it seamlessly with claude --resume <session-id>.

Because Claude Code needs to run in the host's real environment (with access to your toolchain, credentials, and file permissions), RieszManager splits its work between the host and containers. A small daemon called the runner (a systemd user service) runs on the host to read ~/.claude, browse workspace files, and drive claude processes over the stream-json protocol, listening only on a Unix socket accessible to the current user. Meanwhile, the Django backend, frontend web app (PWA), and gateway run inside Docker containers, handling authentication, TOTP two-factor verification, API and real-time connection proxying, and push notifications.

If you often run Claude Code across several projects at once, or want to check on a task from your phone and tap through permission prompts while away from your desk, RieszManager is built for you.

Features

  • Session overview and live status: Lists all sessions on the machine grouped by project, showing in real time which ones are running and which are waiting for your confirmation.
  • Full conversation rendering: Cleanly displays Markdown text, code blocks, tool call cards, and file diffs; a small ring next to the send button shows context usage.
  • Rich input and controls: Queue messages while Claude is running, press Esc to interrupt a run, use slash commands, reference project files with @, upload attachments, and use voice input.
  • Permission prompts and questions: When Claude asks for permission to run a command or edit a file, or asks you a question, approve, deny, or answer right in the browser.
  • Take over terminal sessions: Hand off a Claude Code session currently running in a terminal to the web UI at any time and keep working from there.
  • Project file tree and preview: Browse the workspace directory tree and inspect file contents in the browser, with live webpage previews for HTML files.
  • Push notifications: Supports browser and mobile Web Push notifications, so you get alerted when a task finishes or needs approval even if the tab or PWA is closed.
  • Mobile-friendly and secure: Designed with touch gestures and PWA support for phones; protects sign-in with TOTP two-factor authentication for safe access over HTTPS from outside your network.

Before You Begin

  • A Linux machineMust run systemd and have Claude Code already installed and signed in under your current user account.
  • Python and DockerThe host needs Python 3.10+ (for the runner) along with Docker and Docker Compose v2 (for the backend, frontend, and gateway).
  • A workspace directoryPrepare a single parent directory for your code; each top-level subfolder inside it is recognized as a project.
  • Domain and TLS termination (for external access)The gateway listens only on localhost by default. You do not need a domain to try it locally, but to access it from a phone or over the internet you will need a domain and a TLS terminator (such as Cloudflare Tunnel, Caddy, or nginx).

About Lisi

Lisi (莉思) is the mascot of RieszManager—the sleepy-looking girl with gray-green hair and cat ears on the app icon and sign-in page. You can enable her in Settings as a desktop doll in the corner of the screen: poke her, check your plan usage at a glance, or tap her to insert quick phrases. See Lisi doll for details.
