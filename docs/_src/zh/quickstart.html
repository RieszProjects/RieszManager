快速上手

这一篇带你在一台Linux机器上把Riesz Manager跑起来，先在本机（或通过SSH转发）打开网页试用，并完成第一次对话；想从手机或外网访问、配置HTTPS等，看部署教程。

准备工作

开始之前，请确认你要安装Riesz Manager的机器满足以下条件：

  • 操作系统：Linux，带有systemd。
  • Claude Code：已经安装并完成登录，在当前用户下运行claude能正常对话。
  • Python：3.10或更新版本。
  • Docker：已安装Docker Engine和Docker Compose v2，并且当前用户可以直接执行docker命令（将用户加入docker组后需要重新登录）。

你可以在终端里运行下面几条命令来检查环境是否就绪：

claude --version
python3 --version
docker compose version

后续步骤中的runner和后端容器必须以同一个Linux用户运行（使用相同的UID和GID），请全程使用你平时运行Claude Code的那个用户来操作。

获取代码并初始化

  1. 克隆代码仓库并进入目录：

    git clone https://github.com/RieszProjects/RieszManager.git RieszManager
cd RieszManager

  2. 运行初始化脚本：

    ./rieszctl init

    这个命令会从.env.example生成权限为600的.env文件，并自动完成以下配置：

    • 随机生成RIESZ_SECRET_KEY和RUNNER_TOKEN。
    • 填入当前用户的RIESZ_UID和RIESZ_GID，以及RUNNER_SOCKET_DIR（默认为~/.local/state/riesz-manager/run）。
    • 将WORKSPACE_ROOT设为当前用户的家目录。如果你想在初始化时直接指定其他目录，可以运行WORKSPACE_ROOT=/path ./rieszctl init。
    • 生成一个随机的临时密码并打印在终端上（形如Generated a temporary password: …）。请记下这个密码，稍后登录网页要用到。默认用户名是admin（对应.env里的RIESZ_USERNAME）。

填写配置

用编辑器打开刚刚生成的.env文件，重点检查下面两项：

  • WORKSPACE_ROOT：工作区根目录，必须填写绝对路径。它下面的每个一级文件夹在Riesz Manager里都会被识别为一个项目。例如把WORKSPACE_ROOT设为/home/alice/work，那么~/work/blog和~/work/weather-cli就分别是两个项目。
  • RIESZ_PUBLIC_ORIGIN：网关对外的访问地址。先在本机试用时，把它改成http://127.0.0.1:18573（默认值是一个示例域名，不改的话无法登录）；以后配置了域名和HTTPS，再改成https://你的域名（见配置HTTPS）。

RIESZ_PUBLIC_ORIGIN的值必须和你实际在浏览器地址栏里输入的地址完全一致（包括协议、域名或IP、端口），否则登录会失败。

网关默认监听127.0.0.1:18573（由.env中的RIESZ_BIND和RIESZ_PORT控制），试用阶段不需要改动。

启动

  1. 安装并启动runner服务：

    ./rieszctl runner install

    这条命令会在runner/.venv下创建Python虚拟环境并安装依赖，接着写入systemd用户服务riesz-runner并启动它。脚本还会尝试执行loginctl enable-linger，让服务在你注销SSH会话或机器重启后也能继续运行；如果当前用户没有权限执行这一步，终端会给出提示，按提示手动用sudo运行一次即可。

  2. 构建并启动Docker容器：

    ./rieszctl up

    这会构建并启动backend、frontend、gateway三个容器。第一次运行需要下载镜像并编译前端，大约需要几分钟。

  3. 检查运行状态：

    ./rieszctl status

    它会依次检查runner的socket文件、各个容器的运行状态，以及网关的健康检查接口http://127.0.0.1:18573/api/healthz。

打开网页并登录

如果你正在这台Linux机器的桌面环境前操作，直接打开浏览器访问http://127.0.0.1:18573。

如果Riesz Manager装在远处的机器（例如云服务器）上，先在你自己的电脑终端里执行下面的命令建立SSH本地端口转发，并保持这个连接不断开：

ssh -L 18573:127.0.0.1:18573 用户名@服务器地址

然后在你自己的电脑上打开浏览器，访问http://127.0.0.1:18573。

在登录页填入「用户名」（默认是admin，或你在.env里改过的名字）和「密码」（./rieszctl init打印在终端上的临时密码）。你也可以勾选「在此设备上保持登录」。

第一个会话

登录后，左边栏的「项目」标签下会列出工作区里的所有项目文件夹。

  1. 点任意一个项目名进入项目页。
  2. 在页面底部的输入框里写下你的第一条消息，按Enter发送。注意只有当你发出第一条消息时，这个会话才会被真正创建。
  3. 消息发出后，Claude开始工作，底部状态行会显示当前的执行进度。当Claude需要运行终端命令或修改文件时，对话底部会出现确认卡片，点「允许」即可让它继续，详见确认和提问。
  4. 点开右边项目面板的「文件」标签，可以看到项目目录下的文件列表，点文件名可以直接预览内容，详见项目文件。

在Riesz Manager里创建的会话，同样会保存在机器的~/.claude目录中。你随时可以回到终端，运行claude --resume <会话ID>接着同一个会话继续工作。

接下来做什么

确认基本功能正常后，你可以根据自己的使用场景继续配置：

  • 换掉临时密码：在终端运行./rieszctl hash-password生成RIESZ_PASSWORD_HASH，把它写进.env并删掉明文的RIESZ_PASSWORD，然后运行./rieszctl restart生效。也可以在网页里开启两步验证，详见账号与两步验证。
  • 配置HTTPS后从手机或外网访问：网关默认只监听本机回环地址。想在出门时用手机访问，请配置反向代理与HTTPS证书，详见配置HTTPS。
  • 把网页安装到手机主屏幕：配置好HTTPS后，可以把Riesz Manager添加到手机桌面，像原生应用一样全屏使用，见在手机上用。
  • 开启推送通知：让Claude在完成任务或停下来等你确认时往手机发通知，见推送通知。
  • 了解全部功能：阅读完整的使用指南，了解权限模式、终端里的会话、文件预览、推送通知、莉思玩偶等全部功能。
