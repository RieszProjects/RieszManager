Riesz Manager是什么

Riesz Manager是一个自部署的网页应用，用来在浏览器里集中查看和操控一台机器上的全部Claude Code会话。电脑和手机都能用，手机上还可以安装到主屏幕当成独立应用（PWA）使用。

网页里看到的、发出的消息，都直接对应机器上~/.claude里的会话记录，并不是另起炉灶的副本。在终端里聊了一半的会话可以直接在网页上接着聊；反过来，在网页上继续过的会话，回到终端用claude --resume <会话ID>也能无缝接上。

因为Claude Code必须运行在宿主机的真实环境里（需要用到你的工具链、凭据和文件权限），Riesz Manager分成宿主机和容器两部分协同工作：宿主机上运行一个叫runner的小守护进程（systemd用户服务），负责读取~/.claude、浏览工作区文件，并以stream-json协议驱动claude进程，它只监听仅当前用户可访问的Unix socket；Django后端、前端网页（PWA）和网关则在Docker容器里运行，负责登录鉴权、TOTP两步验证、接口与实时连接的转发以及推送通知。

如果你经常同时在几个项目里跑Claude Code，或者希望离开电脑时用手机看一眼任务跑完没有、顺手点个权限确认，Riesz Manager就是为这种场景准备的。

能做什么

  • 会话总览与状态跟踪：按项目归类列出机器上的全部会话，实时标出哪些正在运行、哪些停下来等待你的确认。
  • 完整渲染对话细节：清晰展示Markdown文本、代码块、工具调用卡片和文件修改diff；发送按钮旁的小圆圈显示上下文用量。
  • 丰富的输入与控制：支持在Claude运行时随时发送排队消息、按Esc中断运行、使用斜杠命令、用@引用项目文件，还可以上传附件和语音输入。
  • 处理权限确认与提问：当Claude请求执行命令、修改文件的权限或向你提问时，直接在网页里点击批准、拒绝或作答。
  • 接管终端会话：正在终端里运行的Claude Code会话，可以随时从网页端接管过来继续操作。
  • 会话之间协作：网页里的会话能和其他Claude Code会话互发消息；需要随时在线的会话可以「保持运行」；会话还能用rieszctl session自己开新会话、分派任务、取回结果。
  • 项目文件树与预览：直接在网页里浏览工作区的文件目录树并查看文件内容，HTML文件还能直接渲染成网页预览。
  • 推送通知：支持浏览器与手机Web Push通知，就算把网页或PWA关掉，任务完成或需要确认时也能收到提醒。
  • 手机适配与安全防护：针对手机屏幕设计了顺手的触摸手势与PWA支持；登录支持TOTP两步验证，配合HTTPS从外网访问也有保障。

在开始之前

  • 一台Linux机器需要带有systemd，并且已经在当前用户下安装、登录好Claude Code。
  • Python与Docker环境宿主机需安装Python 3.10+（运行runner），以及Docker与Docker Compose v2（运行后端、前端和网关）。
  • 工作区文件夹准备一个统一的目录存放代码，它下面的每一个一级子文件夹会被识别为一个项目。
  • 域名与TLS终端（外网访问时）网关默认只监听本机。如果只在本机浏览器试用，不需要域名；如果想从手机或外网访问，需要准备一个域名并配置TLS终端（如Cloudflare Tunnel、Caddy或nginx）。
